# QR Code Generator Pro (PHP + Tailwind CSS)

Application web légère et réactive de génération instantanée de QR Codes (texte, lien et image) avec une interface moderne sous **Tailwind CSS**.

## Features
- ⚡ **Génération en temps réel** (JavaScript) au fur et à mesure de la saisie.
- 🖼️ **Module de téléversement d'image** (PHP) : Convertit l'image en URL publique et génère le QR code associé.
- 🎨 **Personnalisation des couleurs** (Couleur du QR Code & Arrière-plan).
- 📥 **Téléchargement PNG** direct du QR code généré.
- 💎 UI moderne avec **Tailwind CSS** & Icônes **Lucide**.

## Installation
1. Placez les fichiers dans votre serveur local (ex: XAMPP, WAPMServer) ou votre serveur d'hébergement.
2. Assurez-vous que PHP dispose des permissions d'écriture pour créer automatiquement le dossier `uploads/`.
3. Ouvrez `index.php` dans votre navigateur.
